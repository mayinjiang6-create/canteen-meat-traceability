# 快速开始

> 目标：10 分钟内把系统跑起来，看到一条完整溯源链
> 前置：已完成 `PROD-03 部署演示指南` 第 1–3 节的环境准备

---

## 0 你需要先有的东西

| 项 | 要求 | 怎么确认 |
|---|---|---|
| JDK | 21 | `java -version` |
| Maven | 3.9+ | `mvn -v` |
| Node | 22+ | `node -v` |
| MySQL | 8.0+，已启动 | `mysql -u root -p -e "select version();"` |
| 联盟链 | 四节点在跑，WeBASE-Front 可访问 | 浏览器打开 `http://192.168.239.130:5002/WeBASE-Front` |

---

## 1 建库（1 分钟）

```sql
CREATE DATABASE meat_trace DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
CREATE USER 'meat'@'%' IDENTIFIED BY 'Meat@2026';
GRANT ALL PRIVILEGES ON meat_trace.* TO 'meat'@'%';
```

## 2 起后端（3 分钟）

```bash
cd backend
mvn clean package -DskipTests
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

看到这两行就算成功：

```
Flyway ... Successfully applied 2 migrations to schema `meat_trace`
Tomcat started on port(s): 8080
```

> 表结构和演示数据由 Flyway 自动执行，**不要手工建表**。

## 3 起前端（1 分钟）

```bash
cd frontend
npm install
npm run dev
```

打开 `http://localhost:5173`。

## 4 登录（10 秒）

| 账号 | 口令 | 角色 |
|---|---|---|
| `admin` | `Admin@123` | 统一管理员 |
| `supplier01` | `Supp@123` | 供应商（只读） |

## 5 看一条完整链路（2 分钟）

演示数据里 `PR20261118001` 已经是一条完整记录，直接打开：

```
http://localhost:5173/trace/PR20261118001
```

你应该看到：

- 顶部：批次概要（2 个来源、投入 120.000 kg、产出 120.000 kg）
- 中间：**检验结论**卡片（合格）
- 下面：6 条事件的时间线，每条右侧有绿色「记录已核验」
- 底部：核验汇总 `一致 6 / 不一致 0 / 待确认 0 / 不可达 0`

**没有这条数据？** 说明 V2 种子脚本没跑，检查 `application-dev.yml` 里 `flyway.locations` 是否包含 `classpath:db/migration`。

---

## 6 验证链上是真的（1 分钟）

```bash
# 取一条事件标识
curl -s http://localhost:8080/api/public/trace/PR20261118001 \
  | jq -r '.data.timeline[0].eventId'
```

拿这个 `eventId` 去 WeBASE-Front 的「合约调用」里执行 `query`，返回的 `dataDigest` 应与页面上的摘要字段一致。

## 常见问题（30 秒版）

| 现象 | 原因 | 解决 |
|---|---|---|
| `Communications link failure` | MySQL 没起或密码错 | 检查 `application-dev.yml` 的 datasource |
| 页面所有核验徽标变黄 | 链不可达 | 这是**设计预期**，先确认节点在跑 |
| 登录 401 | token 过期（8h） | 重新登录 |
| 表格里数量显示 `120.00099999` | 前端用了 `Number` 解析 | 本项目数量按字符串传输，检查是否被某处转成了 number |
