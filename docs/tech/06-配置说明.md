# 配置说明

> 文档编号：TECH-06 ｜ 版本：v1.0 ｜ 定稿：2026-11-18
> 原则：**配置外置、密钥不入库、两套环境可切换**

---

## 1 配置文件分层

| 文件 | 是否入库 | 内容 |
|---|---|---|
| `application.yml` | ✅ 入库 | 公共配置，不含任何密钥 |
| `application-dev.yml` | ✅ 入库 | 开发环境：本地 MySQL、虚拟机链地址 |
| `application-local.yml` | ❌ **不入库** | 个人口令、真实 API Key（已在 `.gitignore`） |
| 环境变量 | — | 生产/演示机的密钥注入 |

启动时优先级：`application-local.yml` > 环境变量 > `application-dev.yml` > `application.yml`。

## 3 配置项说明

### 3.1 数据源

| 键 | 说明 | 改动风险 |
|---|---|---|
| `spring.datasource.url` | **必须带 `serverTimezone=Asia/Shanghai`** | 时区错会导致 `bizTime` 换算偏移 8 小时，摘要必然不一致 |
| `spring.datasource.password` | 用环境变量 `DB_PASSWORD` 覆盖 | 不要写进 `application-dev.yml` 后提交 |
| `hikari.maximum-pool-size` | 10 足够 | 过大反而在 2 核虚拟机上抢 CPU |

### 3.2 Flyway

| 键 | 值 | 说明 |
|---|---|---|
| `locations` | `classpath:db/migration` | 脚本放在 `backend/src/main/resources/db/migration` 或通过构建复制 |
| `baseline-on-migrate` | `true` | 允许首次在空库上执行 |
| `clean-on-validation-error` | **`false`** | 开发期排查可临时开，**演示前必须关**，否则校验失败会清空全库 |

### 3.3 链

| 键 | 说明 |
|---|---|
| `chain.webase.base-url` | WeBASE-Front 地址；**末尾不要带 `/`** |
| `chain.webase.group-id` | **`group0`**（FISCO BCOS 3.x 用字符串组名） |
| `chain.webase.sign-user-id` | WeBASE-Sign 里的账户，只允许字母数字；写入交易时必填 |
| `chain.webase.user-address` | 该账户地址，部署与部分查询接口需要 |
| `chain.webase.contract-address` | 已部署地址；未部署时接口返回 `50002` |
| `chain.evidence.worker-enabled` | 关闭后所有存证任务停留在 `PENDING`，用于纯业务联调 |
| `chain.evidence.max-retry` | 超过后置 `FAILED`，需人工介入 |
| `chain.evidence.retry-backoff-ms` | 第 n 次重试的等待时间，最后一位复用 |
| `chain.evidence.unknown-result-timeout-ms` | 超时后**先查链**再决定补记或重试（BR-14） |

### 3.4 业务阈值

| 键 | 默认 | 依据 |
|---|---|---|
| `trace.cold-chain.pork-max-temp` | 4.0 ℃ | 冷鲜肉冷链上限 |
| `trace.cold-chain.frozen-max-temp` | -15.0 ℃ | 冻品冷链上限 |
| `trace.quantity.scale` | 3 | **与摘要规范绑定，不可改**；改了历史事件会全部判为不一致 |

### 3.5 AI 问答

| 键 | 说明 |
|---|---|
| `assistant.enabled` | `false` 时前端隐藏入口，接口 404 |
| `assistant.chat.*` | 生成模型（DeepSeek / 通义 / 智谱均可） |
| `assistant.embedding.*` | 向量模型，**必须与建库时一致**，否则检索全乱 |
| `assistant.retrieval.min-score` | 低于此值直接拒答 |
| `assistant.budget.monthly-limit-cny` | 超限自动关闭，防止演示时被扣费 |

> DeepSeek 目前不提供 embedding 接口，所以生成与向量用了两个 provider。这不是设计缺陷，是现实约束——文档里如实写。

## 4 密钥与证书管理

| 资产 | 存放位置 | 是否入库 |
|---|---|---|
| 数据库口令 | 环境变量 `DB_PASSWORD` | ❌ |
| JWT 密钥 | 环境变量 `JWT_SECRET`（≥32 字节） | ❌ |
| 大模型 API Key | 环境变量 `CHAT_API_KEY` / `EMBEDDING_API_KEY` | ❌ |
| FISCO 节点证书 `ca.crt` / `sdk.crt` / `sdk.key` | 虚拟机内，由 WeBASE-Front 挂载 | ❌ |
| 合约 ABI / BIN | `contract/build/` | ✅ （公开信息，可入库） |

`.gitignore` 已覆盖：`*.crt` `*.key` `*.pem` `application-local.yml` `.env`。

**检查是否漏提交密钥**：

```bash
git status --porcelain | findstr /i "key pem crt yml"
# 或
git diff --cached --name-only | grep -E "\.(key|pem|crt)$"
```

> 提交前跑一遍。密钥一旦进了 Git 历史，删文件也删不掉，只能改密钥。

## 5 两套环境对照

| 配置 | 本地开发 | 演示（虚拟机） |
|---|---|---|
| MySQL | `localhost:3306` | 可同本地，或虚拟机 `192.168.239.130:3306` |
| WeBASE-Front | `192.168.239.130:5002` | 同 |
| `evidence.worker-enabled` | 链没通时设 `false` | `true` |
| `assistant.enabled` | 按需 | `true`（答辩亮点） |
| `logging.level` | `DEBUG` | `INFO`（日志太多会拖慢） |
| `flyway.clean-on-validation-error` | 可临时 `true` | **必须 `false`** |

切换方式：

```bash
mvn spring-boot:run -Dspring-boot.run.profiles=dev
java -jar target/meat-trace.jar --spring.profiles.active=demo
```

## 6 常见配置错误

| 现象 | 原因 | 修复 |
|---|---|---|
| 启动报 `Unknown database 'meat_trace'` | 库没建 | 执行 `PROD-03` 第 6 节建库语句 |
| 启动报 `Access denied for user` | 账号没授权 | `GRANT ALL ON meat_trace.* TO 'meat'@'%'` |
| 所有事件摘要对不上 | `serverTimezone` 不是 `Asia/Shanghai` | 改 JDBC URL |
| `chain.webase.base-url` 配了但连不上 | 末尾多了 `/` 或漏了 `/WeBASE-Front` | 用浏览器先验证完整地址 |
| 存证任务永远 `PENDING` | `worker-enabled=false` | 改 `true` 并重启 |
| 问答检索结果风马牛不相及 | 换了 embedding 模型但没重建索引 | 清空 `kb_chunk` 重建 |
| 中文乱码 | 库/表/连接串字符集不统一 | 三处统一 `utf8mb4` |
