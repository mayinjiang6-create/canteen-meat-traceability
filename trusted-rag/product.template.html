一键复现评测

点一下，浏览器会实时跑完 40 条评测题并给出通过率——和仓库里 python demo.py 的结果一致，不是预先写死的数字。

给面试官的 30 秒演示流程（照着点、照着说）
  1. 点「PB20261118001 的检验结论」→ 看绿色答案和下方引用卡片。 说：「每个结论都能点回那条链上核验过的事件，不是模型随口说的。」
  2. 点「那批猪肉验上了没」→ 看黄色拒答。 说：「没有批次号就不硬答，会拒答的系统才可信。」
  3. 点「A 和 B 哪个温度高」→ 看拒答。 说：「知道自己不会什么，比什么都答更专业。」
  4. 点「运行 40 条评测」→ 看全部通过。 说：「所有数字当场可复现，仓库里也有同一份脚本。」

四步讲完，核心就三件事：数据有门槛、答案有出处、不会就拒答。

链上核验186 条事件逐条比对 SHA-256
查询改写口语归一 + 同义归一
双路召回TF-IDF + BM25 → RRF 融合
六类拦截越界 / 比较 / 无锚点等
引用回链grounded 三重校验

页面里的检索逻辑与仓库 trusted_rag.py 同源， 用 verify_product.mjs 做过一致性验证。语料是导出时刻的快照， MATCHED 状态为导出时核验结果。

诚实的边界（面试主动讲更稳）
  • 离线模式是词面混合检索，不是语义 embedding；答案是抽取式呈现，不是 LLM 生成
  • 40 条评测满分不等于真实场景准确率：语料与问题同分布，多为带批次号的精确查询
  • 仍未解决：实体消歧（同名供应商）、无锚点泛问的语义判断
  • 接真 embedding / LLM 后必须重跑评测——换检索器不改评测集，等于没测
